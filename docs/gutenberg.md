# Gutenberg / Block Editor Support

Evently ships full `theme.json` design-token support (colors, typography, spacing, radii as custom properties) plus 14 block patterns and 5 core-block style variations — no JavaScript build step required for any of it.

## Why patterns instead of custom block types

Evently's 14 homepage-style sections (Hero, Event Search, Event Grid, Event Carousel, Categories, Featured Event, Nearby Events, Event Calendar, How It Works, Ticket Preview, Organizer CTA, Testimonials, Blog Grid, CTA) are registered as **block patterns** (`register_block_pattern()`, see `inc/patterns/patterns.php`), not custom Gutenberg block types. A custom dynamic block type needs a JavaScript `registerBlockType()` call (normally compiled via `@wordpress/scripts`); a block pattern needs none — it's server-registered PHP, inserted as ordinary block markup.

Every pattern's content is generated by **capturing the exact same template-part the live homepage uses** (`evently_capture_template_part()`), wrapped in one `core/html` block. This means:

- A pattern always matches the live theme design — there's no second copy of the markup to drift out of sync.
- Adapter-backed sections (Event Grid, Nearby Events, Categories, …) show real current event data at the moment you insert the pattern.
- Interactive sections (Choose calendar, favorites) work immediately — their JS/CSS is enqueued automatically wherever needed.

Find them in the block inserter under the **Evently** category.

## Block style variations

`inc/blocks/blocks.php` registers 5 style variations on core blocks, so you can apply Evently's look to ordinary content without inserting a pattern:

- **Button**: "Evently Accent" (purple), "Evently Ghost" (outline)
- **Group**: "Evently Surface" (soft gray card), "Evently Dark" (dark card)
- **Separator**: "Evently Hairline"

## theme.json

`theme.json` locks the color palette (no custom color picker — the brand palette is deliberately fixed, per the design brief), disables custom gradients/duotone, and exposes the 8px spacing scale, the type scale (hero/h1–h4/body/label/small/caption), and the radius/shadow tokens as `--wp--custom--*` properties usable in any block's Advanced panel.
