# Premium Event Booking Website — Figma Make Prompt

Design and build a **high-end, premium event booking website homepage** for a modern WordPress event booking product that will be sold on ThemeForest/Envato.

The website should feel like a combination of **Airbnb, Eventbrite, Apple, Stripe, and a premium modern SaaS product**, but it must have its own unique visual identity.

The goal is to make the design look expensive, professional, trustworthy, conversion-focused, and production-ready — NOT like a generic WordPress theme.

---

## BRAND

Brand name: **Evently**

Tagline:

**Discover. Book. Experience.**

Evently is a modern event discovery and ticket booking platform for:

* Concerts
* Festivals
* Conferences
* Workshops
* Sports
* Business events
* Food events
* Family events
* Creative events
* Entertainment

---

# DESIGN STYLE

Use a sophisticated, editorial and premium visual style.

Design principles:

* Minimal but visually rich
* Large bold typography
* Cinematic photography
* Strong whitespace
* Clean grid system
* Premium rounded cards
* Subtle borders
* Very subtle shadows
* Large visual sections
* Asymmetric layouts
* Editorial typography
* Sophisticated dark/light contrast
* Subtle micro-interactions
* Modern SaaS UX
* High conversion focus

Avoid:

* Generic Bootstrap appearance
* Excessive gradients
* Excessive glassmorphism
* Excessive shadows
* Cartoon illustrations
* Generic icon-heavy layouts
* Old-fashioned sliders
* Cluttered navigation
* Too many colors
* Excessive animations

The final result must look like a **premium commercial ThemeForest product in 2026**.
